# 게임 정보 통합 웹서비스
여러 사이트에 흩어진 게임 정보를 한곳에서 확인할 수 있는
웹서비스를 개발합니다.

## 주요 기능

첫 버전에 다음 네 영역을 모두 포함합니다.

1. 출시 예정 게임
   - 게임 소개와 플랫폼별 출시 일정
   - 확정·미정 구분과 공식 발표 링크

2. 할인 및 프로모션
   - 스토어별 가격, 할인율, 종료일
   - 구매 페이지 연결

3. 게임 대회
   - 대회와 경기 일정, 진행 상태
   - 공식 중계 연결

4. 게임 산업 이슈
   - 개발 발표, 기업 동향, 정책 및 사회적 이슈
   - 핵심 내용과 원문 링크

## 이용 방식

- 일반 방문자는 로그인 없이 정보를 탐색합니다.
- 관리자는 정보를 등록하고 수정합니다.
- 정보의 출처와 최종 확인 시점을 표시합니다.
